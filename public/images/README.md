# 가게 사진 폴더

여기에 사진 파일을 넣으면 `/images/파일명` 주소로 바로 쓸 수 있습니다.

예) `public/images/seohyeon-kalguksu.jpg` 를 넣었다면
음식점 **수정** 화면의 "사진 주소"에 아래처럼 입력합니다.

```
/images/seohyeon-kalguksu.jpg
```

- 파일명은 영문·숫자·하이픈을 권장합니다 (한글도 되지만 주소가 길어집니다)
- 사진은 가로 1200px 정도면 충분합니다 (카드가 3:2 비율로 잘라서 보여줍니다)
- 직접 찍은 사진을 쓰면 저작권 걱정이 없습니다
